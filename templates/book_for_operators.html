Операторы и встроенные функции Python

Python — это не только красивый синтаксис, но и мощные встроенные инструменты. В этом учебнике ты узнаешь, как принимать ввод от пользователя, работать с числами, строками, типами данных и использовать функции, которые уже ждут тебя «из коробки». Поехали!

1. Ввод данных: функция input()

Функция input() ждёт, пока пользователь введёт текст с клавиатуры, и возвращает его как строку.

name = input("Как тебя зовут? ")
print("Привет,", name)
Важно!

input() всегда возвращает строку (str), даже если пользователь ввёл цифры. Чтобы работать с числами, нужно преобразовать строку с помощью int() или float().

age = input("Сколько тебе лет? ")  # пользователь ввёл "15"
# age — это строка "15", не число!

age = int(age)  # теперь age — число 15
next_year = age + 1
print("В следующем году тебе будет", next_year)
# Можно совместить в одной строке
age = int(input("Сколько тебе лет? "))
print("Через 5 лет будет", age + 5)

2. Типы данных и функция type()

Когда мы пишем программу, очень важно понимать, с каким типом данных мы работаем в данный момент. В Python есть несколько основных типов:

  • str — строка, например "привет" или '123'
  • int — целое число, например 42 или -7
  • float — вещественное число, например 3.14 или -0.5

Иногда мы получаем данные от пользователя через input() и не уверены, что именно там оказалось. Или результат какого-то выражения ведёт себя не так, как мы ожидали. В таких случаях на помощь приходит функция type().

Функция type() принимает один аргумент — любое значение или переменную — и возвращает его тип.

a = 42
print(type(a))   # <class 'int'>

b = 3.14
print(type(b))   # <class 'float'>

c = "привет"
print(type(c))   # <class 'str'>

d = input("Введи что-нибудь: ")
print(type(d))   # <class 'str'> — input всегда возвращает строку!

Важно! Функция type() не изменяет данные, она только показывает, какого они типа. Это как спросить у Python: «Что сейчас лежит в этой переменной?»

Зная тип, мы можем понять, какие операции можно выполнять с данными. Например, строки можно складывать со строками, а числа — с числами. Если попытаться сложить строку и число, Python выдаст ошибку.

3. Преобразование типов: int(), float(), str()

Для того чтобы вводить числа с клавиатуры и потом работать с ними, необходимо найти функцию, которая из строки делает число. И такие функции есть!

Тип данных целых чисел в Python называется int, дробных чисел — float.

Одноимённые функции принимают в качестве аргумента строку и возвращают число, если в этой строке было записано число (иначе выдают ошибку):

a = input()
b = int(a)
print(b + 1)

Или можно написать даже так:

a = int(input())

что будет означать — «получи строку из ввода, сделай из неё целое число и результат помести в переменную a».

Функция int() может быть применена и для получения целого числа из вещественного, в таком случае дробная часть будет отброшена (без округления).

print(int(20.5 + 34.1))  # выдаст 54

Как существует функция int(), которая пытается сделать из того, что ей передали, целое число, так же существует и функция str(), которая возвращает строку из тех данных, что в неё передали.

print(str(10) + str(20))      # выведет '1020'
print(int('10') + int('20'))  # выведет 30

Каждый раз, когда ты пишешь программу, важно понимать, какой тип имеет каждое значение и каждая переменная.

4. Операции над числами

Мы выполняли сложение двух чисел внутри функции print(), но мы можем переменным давать нужные значения и выполнять действия над переменными.

a = 10
b = 20
summ = a + b
print(summ)  # 30

Обратите внимание: если в качестве имени переменной для суммы взять sum, оно выделяется цветом. Это означает, что такое имя знакомо среде и принадлежит какой-то функции, в качестве имени переменной его лучше не использовать.

Как складывать два числа, мы научились. Ещё числа можно вычитать, умножать, делить, возводить в степень, получать целую часть от деления и остаток от деления нацело.

print(30 - 10)   # 20
print(30.0 - 10) # 20.0
print(3 * 3)     # 9

С вычитанием и умножением всё понятно, они аналогичны сложению.

Возведение в степень обозначается двумя звёздочками **, которые должны записываться без разделителей.

print(9 ** 2)  # 81

Обратите внимание: результат деления всегда вещественный, даже если мы делим два целых числа, которые делятся нацело.

print(10 / 2)  # 5.0

Важное замечание о вещественных числах

Компьютер хранит дробные числа с конечной точностью. Из-за этого иногда возникают неожиданные результаты:

print(0.1 + 0.2)  # 0.30000000000000004

Это не ошибка Python, а особенность хранения чисел в памяти. Просто имейте это в виду. В большинстве школьных задач такая погрешность не критична.

5. Целочисленное деление и функция pow()

Для реализации целочисленного деления существуют два действия: деление нацело и остаток от деления нацело. Получение целой части от деления обозначается как удвоенный знак деления //, а остатка от деления нацело — %.

print(10 // 3, 10 % 3)   # 3 1
print(10 // 5, 10 % 5)   # 2 0
print(10 // 11, 10 % 11) # 0 10

Допустим, вам известны результаты a // b, a % b и число b. Как найти число a?

a = 10
b = 3
print((a // b) * b + (a % b))  # 10

Обратите внимание на порядок выполнения действий. Целочисленное деление имеет тот же приоритет, что и обычное деление, значит, будет выполняться раньше, чем вычитание и сложение. Для изменения приоритета выполнения операций используются скобки, всё так же, как в математике.

Функция pow()

Кроме оператора **, для возведения в степень можно использовать встроенную функцию pow(). Она принимает два аргумента: основание и показатель степени.

print(pow(9, 2))  # 81

У функции pow() есть дополнительная возможность — третий аргумент. Если его указать, то результат будет взят по модулю этого числа. Это удобно, когда нужно найти остаток от деления степени на какое-то число.

# 2 в степени 5 равно 32. 32 % 10 = 2
print(pow(2, 5, 10))  # 2

6. Функция divmod()

В Python есть функция, которая возвращает сразу и частное, и остаток от деления. Она называется divmod(). 

candies = 14
friends = 4
each, rest = divmod(candies, friends)
print(each, rest)  # 3 2

Функция возвращает пару чисел, и мы можем распаковать их в две переменные. Это удобно и отлично сочетается с множественным присваиванием.

Приоритет операций

Мы уже изучили несколько типов операций в языке Python:

  • Операцию присваивания (=)
  • Операции сравнения (==, !=, >, <, >=, <=)
  • Арифметические операции (+, -, *, /, %, //)
  • Логические операции (not, and, or)

Все эти операции могут использоваться совместно в довольно сложных конструкциях, поэтому нужно помнить о приоритете операций и в случае необходимости менять его при помощи скобок.

Приоритет выполнения операций в Python от высшего (выполняется первой) до низшего:

  1. Возведение в степень (**)
  2. Унарный минус (-)
  3. Умножение, деление (*, /, %, //)
  4. Сложение и вычитание (+, -)
  5. Операции сравнения (<=, <, >, >=)
  6. Операции равенства (==, !=)
  7. Логические операции (not, and, or)
  8. Операции присваивания (=, +=, -=, *= и т.д.)

PEP 8: По обе стороны бинарной операции нужно обязательно ставить по одному пробелу. Но операции, состоящие из двойных символов (<=, >=, ==, !=, -=, +=), пробелами не разделяются.

7. Функции abs() и round()

abs() — модуль числа

Функция abs() возвращает абсолютное значение числа (модуль).

print(abs(-42))    # 42
print(abs(15))     # 15
print(abs(-3.14))  # 3.14

round() — округление

Для округления чисел используется функция round(). Она принимает число и, опционально, количество знаков после запятой.

x = 10 / 3
print(x)              # 3.3333333333333335
print(round(x, 2))    # 3.33
print(round(x))       # 3

Обратите внимание на особенность: round(2.5) даёт 2, а не 3. Это называется «банковское округление» — к ближайшему чётному числу.

8. Функции max() и min()

Часто требуется найти наибольшее или наименьшее из нескольких чисел. Для этого существуют функции max() и min().

a, b, c = 15, 42, 8
print(max(a, b, c))  # 42
print(min(a, b, c))  # 8

Эти функции можно вызывать с любым количеством аргументов. Они работают и со строками — сравнивают символы по их алфавитному порядку:

print(max("hello"))   # 'o'
print(min("python"))  # 'h'

9. Длина строки: функция len()

Для строки можно определить её длину — количество символов в строке. Для этого используется функция len().

word = input()
length = len(word)
print('Вы ввели слово длиной', length, 'букв.')

Использование в программе функции называется «вызов функции». Он устроен так: пишем имя функции — len, а затем в скобках те данные, которые мы передаём этой функции, чтобы она что-то с ними сделала. Такие данные называются аргументами.

Каждый раз, когда мы пишем имя переменной (кроме самого первого раза — в операции присваивания слева от знака равно), вместо этого имени интерпретатор подставляет значение переменной. Точно так же на место вызова функции подставляется результат её работы, это называется возвращаемое значение функции.

Функции безразлично происхождение значений, которые ей передали в качестве аргумента. Это может быть значение переменной, результат работы другой функции или записанное прямо в коде значение:

print('Это слово длиной', len('абракадабра'), 'букв.')

10. Функции ord() и chr()

Компьютер хранит символы как числа. Каждому символу соответствует свой числовой код. Функция ord() возвращает код символа, а chr() — символ по его коду.

print(ord('A'))   # 65
print(ord('a'))   # 97
print(ord('😊'))  # 128522

print(chr(66))    # 'B'
print(chr(128522))  # '😊'

С помощью этих функций можно, например, вывести весь алфавит или зашифровать сообщение.

11. Системы счисления: bin(), oct(), hex()

Для перевода чисел в двоичную, восьмеричную и шестнадцатеричную системы счисления существуют функции bin(), oct() и hex().

print(bin(42))   # 0b101010
print(oct(42))   # 0o52
print(hex(255))  # 0xff

Префиксы 0b, 0o, 0x обозначают систему счисления: двоичную, восьмеричную и шестнадцатеричную соответственно.
