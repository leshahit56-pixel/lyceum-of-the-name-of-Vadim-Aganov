Знакомство с циклом while

В этом уроке мы познакомимся с оператором цикла while. Цикл позволяет организовать многократное повторение одних и тех же действий. Мы узнаем о логическом типе данных bool и значениях True/False, научимся использовать флаги для управления циклом, а также изучим операторы break и continue для гибкого управления повторениями. Кроме того, мы научимся считать элементы по условию и находить максимум и минимум в потоке данных.

1. Цикл while

Сегодня мы научимся повторять заданные действия несколько раз. Для этого существуют операторы циклов. Мы разберем оператор цикла while. Он выполняет блок кода, пока истинно какое-то условие.

Напомним, условный оператор if проверяет условие и, в зависимости от того, истинно оно или ложно, выполняет либо не выполняет следующий записанный с отступом блок. После этого программа в любом случае выполняется дальше.

Оператор while («пока») тоже проверяет условие и тоже, в случае его истинности, выполняет следующий блок кода (тело цикла). Однако после выполнения этого блока кода выполняется не то, что идет после него, а снова проверяется условие, записанное после while.

Ведь при выполнении тела цикла значения каких-то переменных могли измениться — в результате условие цикла может уже не быть истинным. Если условие все еще истинно, тело цикла выполняется снова. Как только условие цикла перестало выполняться, программа идёт дальше — выполняются команды, записанные после тела цикла.

Условие цикла записывается как и для if: с помощью операций отношения (>, >=, <, <=, !=, ==). Сложные условия можно составлять с помощью логических операций not, and, or.

Действия, расположенные в теле цикла, записываются со смещением вправо на четыре пробела относительно начала слова while.

while условие:
    блок кода (тело цикла)

Важно! Один шаг цикла (выполнение тела цикла) называют итерацией.

Давайте посмотрим программу, в которой цикл будет выполняться, пока не введут число, меньшее или равное 0:

number = int(input())
while number > 0:
    print('Вы ввели положительное число! Вводите дальше.')
    number = int(input())
print('Вы ввели отрицательное число или ноль. Всё.')

Разберемся, как будет работать эта программа. Пользователь вводит число 10. Условие number > 0 истинно, выполняется тело цикла. Внутри цикла выводится сообщение и считывается новое число. Когда пользователь вводит -1, условие становится ложным, и цикл завершается.

2. Логический тип данных bool

До этого момента мы использовали условия в if и while, но не задумывались о том, что само условие — это выражение, у которого есть значение и тип.

Выражения вроде a == b, x > 5 или number != 0 имеют тип bool и принимают одно из двух значений:

  • True (истина)
  • False (ложь)

Тип bool назван в честь математика Джорджа Буля и называется логическим или булевым типом.

print(2 * 2 == 4)   # выведет True
print(5 > 10)       # выведет False

a = 7
b = 7
equal = (a == b)    # переменная equal будет равна True
print(equal)        # выведет True

Над логическими значениями можно выполнять операции not, and, or: 

k = True
print(not k)                # выведет False

x = 5
print(x > 0 and x < 10)     # выведет True

Также существует функция bool(), которая преобразует любое значение в логический тип. Правило простое:

  • 0, 0.0, пустая строка "" — становятся False
  • Всё остальное — становится True
print(bool(0))          # False
print(bool(13))         # True, число не ноль
print(bool(""))         # False, пустая строка
print(bool("hello"))    # True, строка не пустая
print(bool("False"))    # True, строка не пустая!

Логические переменные можно использовать напрямую в условиях:

is_ready = True
if is_ready:
    print('Начинаем работу!')

3. Сигнал остановки

Рассмотрим задачу: пользователь вводит числа. Пусть это будут цены на купленные товары. Ввод -1 — сигнал остановки. Нужно сосчитать сумму всех введенных чисел.

total = 0
print('Вводите цены; для остановки введите -1.')
price = float(input())
while price != -1:
    total += price
    price = float(input())
print('Общая стоимость равна', total)

Обратите внимание: total должен быть равен нулю до начала цикла. Переменная price считывается один раз до цикла и затем обновляется в конце каждой итерации.

4. Флаги: управление циклом через True/False

Переменные логического типа часто используются как флаги — индикаторы того, что какое-то событие произошло.

Флаг — это переменная, которая изначально равна False, а при наступлении определённого события становится True. Потом программа проверяет флаг и в зависимости от его значения выполняет разные действия.

Рассмотрим пример. Программа просит пользователя вводить слова. Если среди них встретится запретное слово «синхрофазотрон», программа запомнит это и в конце выдаст предупреждение.

forbidden_word = 'синхрофазотрон'
print('Вводите слова. Для остановки введите "стоп".')
print('Постарайтесь не ввести слово "' + forbidden_word + '"!')
said_forbidden_word = False    # флаг, что запретное слово ещё не сказано

word = input()
while word != 'стоп':
    if word == forbidden_word:
        said_forbidden_word = True    # поднимаем флаг
    word = input()

if said_forbidden_word:
    print('Вы нарушили инструкции.')
else:
    print('Спасибо, что ни разу не упомянули', forbidden_word)

Важно! Флагам нужно давать осмысленные имена, которые отражают их смысл: found_value, mission_accomplished, is_running, has_error. Это делает код понятным.

5. Бесконечный цикл и оператор break

Иногда удобнее проверять условие выхода не в заголовке цикла, а внутри тела. Для этого создают бесконечный цикл с помощью while True и выходят из него оператором break.

break немедленно прекращает выполнение цикла. Программа переходит к командам, записанным после тела цикла.

Перепишем программу с сигналом остановки через while True:

total = 0
print('Вводите цены; для остановки введите -1.')
while True:
    price = float(input())
    if price == -1:
        break
    total += price
print('Общая стоимость равна', total)

Теперь не нужно дублировать input() до цикла и внутри. Цикл работает бесконечно, пока не сработает break.

Сравним два подхода. Вот программа с флагом:

count = 0
exit_loop = False
while not exit_loop:
    print("Введите 'e' для выхода или любую клавишу для продолжения:")
    sm = input()
    if sm == 'e':
        exit_loop = True
    else:
        count += 1
print("Вы зашли в цикл", count, "раз(а)")

А теперь та же программа с break:

count = 0
while True:
    print("Введите 'e' для выхода или любую клавишу для продолжения:")
    sm = input()
    if sm == 'e':
        break
    count += 1
print("Вы зашли в цикл", count, "раз(а)")

Второй вариант короче, в нём меньше переменных и вложенных блоков. Однако злоупотреблять break не стоит: когда программист читает код, он ожидает, что цикл завершился потому, что условие в заголовке стало ложным. Если выход происходит по break, логика становится менее очевидной.

6. Оператор continue

Оператор continue немедленно завершает текущую итерацию цикла и переходит к следующей. Всё, что написано после continue в теле цикла, не выполняется.

Пример: суммируем только положительные числа, отрицательные пропускаем. Ввод 0 — сигнал остановки.

total = 0
while True:
    number = int(input())
    if number == 0:
        break
    if number < 0:
        print('Отрицательные числа пропускаются.')
        continue
    total += number
print('Сумма положительных чисел:', total)

Осторожно! Если поставить continue до изменения переменной, которая должна меняться на каждой итерации, можно получить бесконечный цикл:

count = 1
while count < 100:
    if count % 5 == 0:
        continue    # ОШИБКА! count не увеличится, цикл бесконечный!
    print(count)
    count += 1

Когда count станет равен 5, сработает continue, и count += 1 не выполнится. count навсегда останется 5.

7. Подсчет количества элементов, удовлетворяющих условию

Рассмотрим задачу: пользователь вводит целые числа. Ввод прекращается, если введено число 0. Необходимо определить, сколько чисел оканчивались на 2 и были кратны 4.

count = 0
number = int(input())
while number != 0:
    if number % 10 == 2 and number % 4 == 0:
        count += 1
    number = int(input())
print('Количество искомых чисел:', count)

Обратите внимание: до цикла необходимо задать count = 0. При каждой подходящей проверке счётчик увеличивается на 1.

8. Поиск максимума и минимума

Часто нужно найти максимальное или минимальное значение среди введённых чисел.

Алгоритм поиска максимума:

  1. Завести переменную для максимума, присвоить ей очень маленькое значение (или первый элемент).
  2. В цикле сравнивать каждый новый элемент с максимумом.
  3. Если элемент больше — обновить максимум.

Пример: найти самую толстую книгу. Ввод 0 — конец списка.

max_pages = 0
n = int(input())
while n != 0:
    if n > max_pages:
        max_pages = n
    n = int(input())
print(max_pages)

Важно! Если числа могут быть отрицательными, начальное значение 0 не подойдёт. Лучше использовать первое введённое число или -999999.

Поиск минимума аналогичен:

min_value = 999999
n = int(input())
while n != 0:
    if n < min_value:
        min_value = n
    n = int(input())
print(min_value)

Можно искать и то, и другое одновременно:

max_value = -999999
min_value = 999999
n = int(input())
while n != 0:
    if n > max_value:
        max_value = n
    if n < min_value:
        min_value = n
    n = int(input())
print('Максимум:', max_value)
print('Минимум:', min_value)
