Строки. Индексация и срезы

На этом занятии мы углубим свои знания о строках. Мы научимся склеивать и умножать строки, форматировать вывод с помощью f-строк, получать отдельные символы по индексу, перебирать строку в цикле, извлекать подстроки с помощью срезов, сравнивать строки, а также узнаем, как тексты хранятся в памяти компьютера.

1. Строка как коллекция

На прошлых занятиях мы познакомились с коллекциями, которые могут хранить несколько значений под одним именем. Но ещё до изучения множеств и списков мы уже знали тип данных, который ведёт себя подобно коллекции. Этот тип данных — строка. Строка фактически является последовательностью символов. В Python нет отдельного типа для одного символа, поэтому можно сказать, что строка — это последовательность односимвольных строк.

2. Что мы знаем о строках

Давайте вспомним, что мы уже знаем о работе со строками в Python:

  • Создавать строки: напрямую в кавычках, через input(), через str()
  • Узнавать длину строки: len()
  • Проверять вхождение: оператор in
fixed_word = 'опять'
word = input()
number = 25
number_string = str(number)
word_plus_number = fixed_word + number_string

print(len(word_plus_number))
print('оп' in word_plus_number)

3. Конкатенация и умножение строк

Строки можно склеивать с помощью оператора +. Это называется конкатенацией:

first = 'Привет'
second = 'мир'
result = first + ', ' + second + '!'
print(result)  # Привет, мир!

Строки можно умножать на целое число с помощью оператора *. Это повторяет строку указанное количество раз:

print('А' * 5)      # ААААА
print('Ха' * 3)     # ХаХаХа
print('-' * 20)     # --------------------

Умножение строк удобно для рисования разделителей, рамок и повторяющихся узоров.

4. Форматирование строк (f-строки)

Часто нужно вставить значения переменных внутрь строки. Самый удобный способ в современном Python — f-строки. Перед открывающей кавычкой ставится буква f, а внутри строки в фигурных скобках {} пишутся имена переменных или выражения:

name = 'Вадим Маликович'
age = 29
print(f'Меня зовут {name}, мне {age} лет.')
# Меня зовут Вадим Маликович, мне 29 лет.

В фигурных скобках можно писать не только переменные, но и целые выражения:

a = 10
b = 20
print(f'Сумма {a} и {b} равна {a + b}')
# Сумма 10 и 20 равна 30

f-строки делают код чище и понятнее, чем склеивание через +.

5. Индексация в строках

В строках важен порядок символов. Строки МИР и РИМ — две совершенно разные строки. Наличие порядка даёт возможность пронумеровать символы. Нумерация начинается с 0.

По индексу можно получить соответствующий символ строки. Для этого нужно после строки (или переменной, содержащей строку) написать в квадратных скобках индекс символа:

word = 'привет'
initial_letter = word[0]  # 'п'
other_letter = word[3]    # 'в'

Если попытаться получить символ по несуществующему индексу, Python выдаст ошибку IndexError: string index out of range.

Индекс может быть не только фиксированным числом, но и переменной или результатом вычислений:

word = 'привет'
number_of_letter = int(input())  # пользователь ввёл 3
print(word[number_of_letter])    # выведет 'в'

Отрицательные индексы

Кроме «прямой» индексации, в Python разрешены отрицательные индексы: word[-1] — последний символ, word[-2] — предпоследний, и так далее.

word = 'привет'
print(word[-1])  # 'т'
print(word[-2])  # 'е'

Неизменяемость строк

Можно ли изменить отдельный символ строки? Нет:

word = 'карова'      # написали с ошибкой
word[1] = 'о'         # Ошибка! TypeError: 'str' object does not support item assignment

Строки в Python — неизменяемый тип данных. Чтобы исправить ошибку, нужно создать новую строку, например, с помощью срезов:

word = 'карова'
word = word[:1] + 'о' + word[2:]  # 'корова'

6. Перебор элементов строки

Цикл for можно использовать для перебора всех символов строки:

text = 'hello, my dear friends!'
vowels = 0
for letter in text:
    if letter in 'aeiouy':
        vowels += 1
print(f'Количество гласных: {vowels}')

Так как символы в строке пронумерованы, есть и второй способ — перебрать все индексы через range(len()):

text = 'hello, my dear friends!'
vowels = 0
for i in range(len(text)):
    if text[i] in 'aeiouy':
        vowels += 1
print(f'Количество гласных: {vowels}')

Второй способ удобен, когда нужно знать не только символ, но и его позицию в строке.

7. Срезы строк

Срез (slice) — это способ получить часть строки без использования цикла. Срез записывается в квадратных скобках с двоеточием: [start:stop:step].

  • start — начальный индекс (включительно)
  • stop — конечный индекс (не включительно)
  • step — шаг (необязательно)
text = 'Hello, world!'
print(text[0:5])     # 'Hello'
print(text[7:12])    # 'world'

Если не указать начальный индекс, срез берётся от начала строки. Если не указать конечный — до конца строки:

text = 'Hello, world!'
print(text[:5])      # 'Hello'
print(text[7:])      # 'world!'

Отрицательные индексы работают и в срезах:

full_name = 'Иванов И. И.'
surname = full_name[:-6]  # 'Иванов'

Шаг в срезах

Третий параметр — шаг. Например, чтобы взять каждый второй символ:

number = '123456'
print(number[::2])   # '135' — символы на позициях 0, 2, 4
print(number[1::2])  # '246' — символы на позициях 1, 3, 5

Отрицательный шаг позволяет пройти по строке в обратном порядке:

text = 'привет'
print(text[::-1])    # 'тевирп' — строка задом наперёд

Переворот строки через [::-1] — один из самых популярных трюков в Python.

Выход за границы

В отличие от индексации, при выходе за границы в срезе ошибки не будет — вернётся только то, что помещается в допустимые индексы:

a = 'Python'
print(a[2:10000])  # 'thon'
print(a[999:])     # пустая строка

8. Сравнение строк

Строки можно сравнивать между собой с помощью операторов ==, !=, <, >, <=, >=. Сравнение происходит лексикографически (как в словаре) — по порядку символов.

print('abc' == 'abc')  # True
print('abc' != 'def')  # True
print('abc' < 'def')   # True (a раньше d)
print('абв' < 'где')   # True

Важно помнить, что сравнение идёт по кодам символов. Заглавные буквы имеют меньшие коды, чем строчные:

print('А' < 'а')         # True
print('Apple' < 'apple') # True

При сравнении чисел в виде строк результат может быть неочевидным:

print('123' < '45')      # True, потому что '1' < '4'

Чтобы сравнить строки как числа, их нужно сначала преобразовать в int().

9. Хранение текстов в памяти компьютера

Компьютер умеет хранить только двоичные числа. Для записи текстов прибегают к кодированию — сопоставлению кодов текстовым символам.

Таблица ASCII

Один из первых стандартов — таблица ASCII. Изначально 7-битные коды (128 символов): латинские буквы, цифры, знаки препинания, спецсимволы. Позже расширили до 1 байта (256 символов), добавив кириллицу и псевдографику.

Юникод

Сейчас стандартом является Юникод — таблица, содержащая соответствия между числом и символом практически для всех письменностей мира. В Юникод постоянно добавляются новые символы, включая эмодзи:

print('\u2603')  # ☃ (снеговик)

В Python все строки хранятся как последовательность юникод-символов. Функции ord() и chr() позволяют работать с кодами символов напрямую.
