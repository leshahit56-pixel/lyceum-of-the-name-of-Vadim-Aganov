Инструменты для строк и списков

Ты уже знаешь, как устроены строки и списки, умеешь обращаться к элементам по индексам, делать срезы и перебирать их в циклах. Теперь пора познакомиться с встроенными инструментами, которые делают работу с этими структурами ещё удобнее и быстрее. Мы разберём основные методы строк и списков, которые чаще всего пригождаются в реальных задачах.

Часть 1. Инструменты для строк

Строки — это неизменяемые последовательности символов. Хотя саму строку изменить «на месте» нельзя, у неё есть множество методов, которые возвращают новую строку с нужными преобразованиями. Все эти методы вызываются через точку после строки или переменной, содержащей строку.

1. Изменение регистра

word = "PyThOn"
print(word.upper())        # PYTHON
print(word.lower())        # python
print(word.capitalize())   # Python (первая буква заглавная, остальные строчные)
print(word.title())        # Python (каждое слово с заглавной)

Эти методы удобны, когда нужно привести весь ввод пользователя к одному регистру перед сравнением.

2. Поиск и подсчёт символов

Методы find() и count() помогают искать подстроки в строке.

текст = "Привет, мир! Прекрасный мир."
print(текст.find("мир"))       # 8 — индекс первого вхождения
print(текст.find("мир", 10))   # 20 — поиск начиная с 10-го индекса
print(текст.find("нету"))      # -1 — если не найдено (ошибки не будет)
print(текст.count("мир"))      # 2 — количество вхождений
print(текст.count("о"))        # 0 — тоже можно считать отдельные символы

В отличие от оператора in, который просто отвечает «да» или «нет», find() возвращает позицию, а count() — точное количество.

3. Проверка содержимого

Иногда нужно узнать, состоит ли строка только из цифр, букв и т.п.

print("123".isdigit())      # True
print("12a".isdigit())      # False
print("Hello".isalpha())    # True (только буквы)
print("Hello123".isalnum()) # True (буквы и цифры)
print("   ".isspace())      # True (только пробельные символы)

4. Удаление пробелов: strip(), lstrip(), rstrip()

Пользователи часто вводят лишние пробелы в начале или в конце строки. Эти методы аккуратно их убирают.

name = "   Алексей   \n"
print(f"'{name}'")                   # '   Алексей   \n'
print(f"'{name.strip()}'")          # 'Алексей'
print(f"'{name.lstrip()}'")         # 'Алексей   \n' (слева убрали)
print(f"'{name.rstrip()}'")         # '   Алексей' (справа убрали)

# можно указать конкретные символы для удаления
text = "...===...заголовок...===..."
print(text.strip("."))               # ===...заголовок...===
print(text.strip(".="))              # заголовок

Очень полезно при обработке данных из файлов или с клавиатуры.

5. Замена подстрок: replace()

Метод replace() меняет одну подстроку на другую во всей строке.

сообщение = "Я люблю Java. Java — классный язык."
новое = сообщение.replace("Java", "Python")
print(новое)  # Я люблю Python. Python — классный язык.

# можно ограничить количество замен
новое_одна = сообщение.replace("Java", "Python", 1)
print(новое_одна)  # Я люблю Python. Java — классный язык.

6. Разбиение и склеивание: split() и join()

Это главные инструменты для превращения строки в список и наоборот.

# split() — из строки в список по разделителю
data = "яблоко,банан,вишня"
fruits = data.split(",")
print(fruits)   # ['яблоко', 'банан', 'вишня']

# по пробелам (по умолчанию разделитель — любой пробельный символ)
words = "один два   три".split()
print(words)    # ['один', 'два', 'три']
# join() — из списка в строку, склеивая элементы указанной строкой-разделителем
words = ['Hello', 'world']
sentence = ' '.join(words)      # "Hello world"
path = '/'.join(['usr', 'bin', 'python'])  # "usr/bin/python"

# склеивание без разделителя:
digits = ['1', '2', '3']
number = ''.join(digits)        # "123"

Обрати внимание: join() — это метод самой строки-разделителя, но в скобках передаётся список строк. Если в списке есть числа, их сначала нужно преобразовать в строки.

7. Дополнительные методы

print("hello".startswith("he"))   # True
print("hello".endswith("lo"))     # True
print("42".zfill(5))              # "00042" — дополняет нулями слева до указанной длины
Важно помнить: все эти методы возвращают новую строку, исходная никогда не меняется. Если нужно сохранить результат, обязательно присвой его переменной.

Часть 2. Инструменты для списков

В отличие от строк, списки изменяемы, и большинство методов меняют их «на месте», ничего не возвращая. Будь внимателен: часто новички пытаются написать список = список.метод(), что приводит к потере данных.

1. Добавление элементов: append(), insert(), extend()

append() добавляет один элемент в конец, insert() — на заданную позицию, extend() — сразу несколько элементов из другого списка.

numbers = [1, 2, 3]
numbers.append(4)           # [1, 2, 3, 4]
numbers.insert(0, 0)        # [0, 1, 2, 3, 4]
numbers.extend([5, 6, 7])   # [0, 1, 2, 3, 4, 5, 6, 7]

Заметь, что все три метода изменяют исходный список и ничего не возвращают (точнее, возвращают None).

2. Удаление элементов: remove(), pop(), clear() и del

Способов удалить элемент несколько, и у каждого своя особенность.

items = [10, 20, 30, 20, 40]

# remove(значение) — удаляет первое вхождение
items.remove(20)
print(items)   # [10, 30, 20, 40]

# pop() — удаляет по индексу и возвращает удалённый элемент
last = items.pop()     # удаляет последний
print(last)            # 40
print(items)           # [10, 30, 20]

second = items.pop(1)  # удаляет элемент с индексом 1
print(second)          # 30
print(items)           # [10, 20]

# clear() — полностью очищает список
items.clear()
print(items)           # []

# del — оператор языка Python, не метод, тоже удаляет элемент по индексу
nums = [1, 2, 3, 4]
del nums[1]
print(nums)            # [1, 3, 4]
Осторожно с remove(): если элемент не найден, Python вызовет ошибку ValueError. Поэтому перед удалением лучше проверить наличие через in.

3. Поиск и подсчёт: index() и count()

Как и у строк, но применяются к элементам списка.

colors = ['красный', 'синий', 'зелёный', 'синий']
print(colors.index('синий'))   # 1 (индекс первого вхождения)
print(colors.count('синий'))   # 2 (сколько раз встречается)
# если элемента нет — index() вызовет ошибку, count() вернёт 0

4. Сортировка и переворот: sort() и reverse()

Метод sort() упорядочивает список по возрастанию (или по убыванию, если указать reverse=True). reverse() просто переворачивает порядок элементов.

a = [3, 1, 4, 1, 5]
a.sort()
print(a)   # [1, 1, 3, 4, 5]

b = ['яблоко', 'апельсин', 'банан']
b.sort(reverse=True)
print(b)   # ['яблоко', 'банан', 'апельсин'] (по алфавиту в обратном порядке)

c = [1, 2, 3]
c.reverse()
print(c)   # [3, 2, 1]

Оба метода работают «на месте» и ничего не возвращают. Если нужно сохранить исходный список, сначала сделай копию.

5. Копирование: copy()

Простое присваивание new = old не создаёт нового списка, а только даёт ему ещё одно имя. Настоящую копию делают так:

original = [1, 2, 3]
copy = original.copy()
copy.append(4)
print(original)   # [1, 2, 3] — не изменился
print(copy)       # [1, 2, 3, 4]

Также копию можно получить срезом original[:] или функцией list(original).

6. Полезные функции для списков (min, max, sum)

Для списков, состоящих из чисел, очень удобны встроенные функции:

nums = [7, 2, 9, 4, 3]
print(min(nums))   # 2
print(max(nums))   # 9
print(sum(nums))   # 25

Они работают только с числами. Попытка применить их к списку строк вызовет ошибку.

4. Заключение

Теперь в твоём арсенале — все ключевые методы для работы со строками и списками. Не старайся запомнить их все сразу. Просто знай, что они существуют, и при необходимости подсматривай в справочник. Со временем пальцы сами будут набирать .split() или .append() без раздумий. Удачи в задачах!
