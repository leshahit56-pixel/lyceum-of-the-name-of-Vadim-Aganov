Цикл for

Сегодня мы изучим ещё один оператор цикла — for. Он выполняет блок кода заданное количество раз. Ты научишься работать с функцией range(), перебирать строки, использовать оператор in, создавать вложенные циклы и управлять повторениями с помощью break и continue.

1. Цикл for

Цикл for выполняет блок кода заданное количество раз.

for переменная in range(количество):
    тело цикла

Как и у while, у цикла for есть заголовок, заканчивающийся двоеточием, и тело цикла с отступом в четыре пробела. Переменная на начальной итерации принимает значение 0, на следующей — 1, и так далее, до значения, указанного в range(), не включая его.

Вот программа, которая выводит на экран целые числа от 0 до n (не включительно):

n = int(input())
for i in range(n):
    print(i)

range означает «диапазон». for i in range(n) читается как «для всех i в диапазоне от 0 до n (не включительно)». Цикл выполняется n раз.

Перепишем задачу с тремя товарами через for:

total = 0
for i in range(3):
    price = float(input())
    total += price
print('Сумма введённых чисел равна', total)

Переменная-счётчик изменяется сама в рамках заданных значений. Цикл for присваивает переменной i значения 0, 1, 2 автоматически.

2. Соглашения об именовании переменных

В абстрактных задачах допустимы короткие имена вроде n или i. Однако лучше избегать этого. Буквой n обычно обозначают количество чего-либо, буквами i и j — итераторы цикла for. Если есть определённость (например, количество автомобилей), называйте переменную понятно: cars.

3. Начальное значение и шаг итератора в range

В скобках после range можно записать не одно, а два или три числа.

  • Одно число — итератор идёт от 0 до заданного значения (не включая).
  • Два числа — начальное и конечное значение итератора.
  • Три числа — начальное, конечное и шаг итератора.
# от 1 до 10
for i in range(1, 11):
    print(i)

# от 1 до 10 с шагом 2 (1, 3, 5, 7, 9)
for i in range(1, 11, 2):
    print(i)

# от 10 до 1 (обратный порядок)
for i in range(10, 0, -1):
    print(i)

4. Перебор строк в цикле for и оператор in

Цикл for умеет перебирать не только числа из range(), но и символы строки. На каждой итерации переменная цикла принимает значение очередного символа строки.

word = input('Введите слово: ')
for char in word:
    print(char)

Если ввести привет, программа выведет каждую букву на отдельной строке.

Это удобно для задач, где нужно обработать каждый символ: посчитать гласные, найти определённую букву или просто вывести слово по буквам.

Оператор in для проверки вхождения

Часто нужно проверить, содержится ли символ в наборе других символов. Для этого используется оператор in. Он возвращает True, если значение найдено в строке, и False в противном случае.

print('а' in 'привет')   # False
print('е' in 'привет')   # True
print('ри' in 'привет')  # True — можно искать не только один символ!

Оператор in удобно использовать в условии if:

char = 'а'
if char in 'аеёиоуыэюя':
    print('Гласная!')

Пример: подсчёт гласных букв в слове.

word = input()
vowels = 'аеёиоуыэюя'
count = 0
for char in word:
    if char in vowels:
        count += 1
print('Количество гласных:', count)

Также с помощью in можно проверить, есть ли определённый символ в строке вообще:

word = input()
if 'ъ' in word:
    print('В слове есть твёрдый знак!')
else:
    print('Твёрдого знака нет.')

5. Вложенные циклы for

Один цикл for можно поместить внутрь другого. Это называется вложенным циклом. Внутренний цикл полностью выполняется на каждой итерации внешнего.

for i in range(3):
    for j in range(2):
        print(i, j)
# 0 0
# 0 1
# 1 0
# 1 1
# 2 0
# 2 1

Вложенные циклы удобны для вывода таблиц, прямоугольников и других двумерных структур.

Таблица умножения:

for i in range(1, 10):
    for j in range(1, 10):
        print(i * j, end='\t')
    print()  # переход на новую строку

Прямоугольник из звёздочек:

height = 3
width = 5
for i in range(height):
    for j in range(width):
        print('*', end='')
    print()

Треугольник из звёздочек:

n = 5
for i in range(1, n + 1):
    for j in range(i):
        print('*', end='')
    print()

6. Операторы break и continue в цикле for

Операторы break и continue работают в цикле for точно так же, как в while.

  • break — немедленно прекращает выполнение цикла.
  • continue — пропускает оставшуюся часть тела цикла и переходит к следующей итерации.

Пример с break:

for i in range(10):
    if i == 5:
        break
    print(i)
# выведет 0, 1, 2, 3, 4

Пример с continue:

for i in range(5):
    if i == 2:
        continue
    print(i)
# выведет 0, 1, 3, 4

Пример: поиск буквы в слове с досрочным выходом

word = input()
for char in word:
    if char == 'ъ':
        print('Найден твёрдый знак!')
        break
else:
    print('Твёрдого знака нет.')

Обратите внимание на блок else после for. Он выполняется, только если цикл не был прерван оператором break.

7. Когда какой цикл использовать

  • while — когда кусок кода должен выполниться несколько раз, но заранее неизвестно, сколько именно. Например, до ввода сигнала остановки.
  • for — когда кусок кода должен выполниться несколько раз, и количество итераций известно до начала цикла. Например, перебрать все символы строки или числа от 1 до N.
