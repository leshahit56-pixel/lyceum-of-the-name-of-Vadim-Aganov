Условный оператор и общение с пользователем

Привет, будущий программист! Ты уже умеешь выводить данные на экран с помощью print() и управлять разделителями sep и end. Теперь настало время научить программу принимать решения и «общаться» с тобой. В этом уроке ты узнаешь, как запрашивать информацию у пользователя, хранить её в переменных и менять ход программы в зависимости от полученных ответов. Это как раз тот момент, когда код становится по‑настоящему интерактивным!

1. Как программа получает данные: функция input()

До сих пор мы только выводили текст на экран. Но что, если мы хотим, чтобы пользователь сам вводил числа или слова? Для этого существует встроенная функция input(). 

name = input("Как тебя зовут? ")
print("Привет,", name)

Когда Python доходит до строки с input(), он останавливается и ждёт, пока пользователь наберёт что‑то на клавиатуре и нажмёт Enter. Всё, что было введено, становится строкой и сохраняется в переменной name.

Переменная — это как коробочка с именем, в которую можно положить значение и потом использовать его в программе. В примере выше мы положили в коробочку с названием name то, что ввёл пользователь, а затем передали это в print().

Важно!

input() всегда возвращает строку, даже если пользователь ввёл цифры. Если написать age = input("Сколько тебе лет? ") и ввести 15, то в переменной age будет строка "15", а не число 15. Позже мы научимся превращать строки в числа с помощью int() и float().

2. Переменные и типы данных

Переменные могут хранить данные разных типов. Пока нам понадобятся два:

  • str — строка, текст в кавычках: "привет", '42'.
  • int — целое число: 42, -7, 0.

Чтобы превратить строку в целое число, используется функция int(). Например: 

age_str = input("Сколько тебе лет? ")
age = int(age_str)
print("Через год тебе будет", age + 1)

Можно совместить обе операции в одной строке: 

age = int(input("Сколько тебе лет? "))
print("Ты родился примерно в", 2026 - age, "году")

Если попытаться превратить в число строку, которая не состоит из цифр, Python выдаст ошибку. Поэтому будь внимателен и всегда проверяй, что именно ты передаёшь в int().

3. Почему программа должна принимать решения

Представь, что ты пишешь программу‑охранника для секретного клуба. Она спрашивает возраст и говорит, можно ли войти. Или игру, где нужно угадать число. Во всех этих случаях код должен выполнять разные действия в зависимости от условий. Для этого существует условный оператор.

Прежде чем использовать его, нужно научиться задавать вопросы, на которые Python может ответить «да» или «нет».

4. Операторы сравнения

Чтобы сравнивать значения, используют специальные операторы. Результат сравнения — всегда либо True (истина), либо False (ложь).

Оператор Значение Пример
== равно 5 == 5 → True
!= не равно 5 != 3 → True
< меньше 3 < 5 → True
> больше 10 > 7 → True
<= меньше или равно 4 <= 4 → True
>= больше или равно 6 >= 5 → True

Эти операторы работают не только с числами, но и со строками (сравнивают по алфавиту, но об этом позже).

5. Простейшее условие: if

Конструкция if (англ. «если») говорит Python: «выполни следующий блок кода только если условие истинно». Синтаксис: 

if условие:
    блок кода

Обрати внимание на двоеточие после условия и на отступ (обычно 4 пробела) у строк, которые относятся к if. Отступы в Python — это не украшение, а требование языка. Если забыть отступ или сделать его неправильно, программа сломается.

Рассмотрим пример — программа, которая пускает в клуб только тех, кому 18 или больше:

age = int(input("Введи свой возраст: "))
if age >= 18:
    print("Добро пожаловать в клуб!")
print("Программа завершена.")

Если пользователь введёт 20, он увидит и приглашение, и завершающее сообщение. Если 15 — только «Программа завершена», потому что условие age >= 18 ложно и блок внутри if пропускается.

6. Блоки кода и отступы

В Python всё, что сдвинуто на одинаковое количество пробелов под оператором if (или под любым другим оператором, который открывает блок), считается его частью. Как только отступ заканчивается — блок завершён. 

password = input("Введи пароль: ")
if password == "secret":
    print("Доступ разрешён.")
    print("Добро пожаловать в систему.")
print("До свидания.")

Здесь оба сообщения с отступом выполнятся только при верном пароле. Сообщение «До свидания» выводится всегда, потому что у него нет отступа.

Распространённая ошибка: смешивание пробелов и табуляций. Используй всегда или 4 пробела, или только Tab. В любом редакторе можно настроить, чтобы Tab вставлял 4 пробела.

7. Полная вилка: if-else

Часто нужно выполнить одно действие, если условие истинно, и совсем другое — если ложно. Тогда добавляют else (англ. «иначе»). 

if условие:
    блок А
else:
    блок Б

Программа выполняет либо блок А, либо блок Б, но не оба сразу.

Перепишем пример с клубом, добавив вежливый отказ:

age = int(input("Введи свой возраст: "))
if age >= 18:
    print("Добро пожаловать!")
else:
    print("Извини, вход только для взрослых.")
print("Хорошего дня!")

8. Несколько вариантов: if-elif-else

Если возможных вариантов больше двух, на помощь приходит elif (сокращение от «else if»). Python проверяет условия по порядку и выполняет первый же истинный блок. Если ни одно не подошло — срабатывает else. 

if условие1:
    блок1
elif условие2:
    блок2
elif условие3:
    блок3
else:
    блок_иначе

Количество elif не ограничено. else можно не писать, если оно не нужно.

Пример: программа определяет время суток по введённому часу. 

hour = int(input("Который час? (введи число от 0 до 23): "))
if hour < 6:
    print("Ночь")
elif hour < 12:
    print("Утро")
elif hour < 18:
    print("День")
elif hour < 24:
    print("Вечер")
else:
    print("В сутках нет такого часа!")

Проверь, как это работает: если ввести 3 — «Ночь», 7 — «Утро», 14 — «День», 20 — «Вечер», 25 — предупреждение.

9. Вложенные условия

Один if можно поместить внутрь другого. Это называется вложенным условием. Будь особенно внимателен с отступами — каждый вложенный блок добавляет ещё 4 пробела. 

temperature = int(input("Температура воздуха: "))
if temperature > 25:
    print("Жарко")
    if temperature > 35:
        print("Носи головной убор!")
else:
    print("Прохладно")
    if temperature < 0:
        print("Надень шапку и шарф.")

Сначала проверяется внешнее условие. Если оно истинно, программа заходит в его блок и там может встретить ещё один if. Так можно строить сложные логические цепочки.

10. Логические операторы

Иногда нужно проверить сразу несколько условий. Для этого используют логические операторы:

  • and — оба условия должны быть истинны.
  • or — хотя бы одно условие истинно.
  • not — меняет истинность на противоположную.

Пример: программа, которая проверяет, является ли число трёхзначным. 

num = int(input("Введи целое число: "))
if num >= 100 and num <= 999:
    print("Это трёхзначное число.")
else:
    print("Это не трёхзначное число.")

Здесь условие num >= 100 and num <= 999 истинно только тогда, когда число и больше или равно 100, и меньше или равно 999 одновременно.

Пример с or: выходной день. 

day = input("Какой сегодня день? ")
if day == "суббота" or day == "воскресенье":
    print("Ура, выходной!")
else:
    print("Пора на учёбу.")

А оператор not часто используют для проверки противоположного: 

password = input("Пароль: ")
if not password:
    print("Пароль не может быть пустым!")
else:
    print("Пароль принят.")

Здесь not password означает «если пароль пустая строка». Пустая строка считается ложным значением, поэтому not превращает её в истину, и мы попадаем в блок предупреждения.

11. Типичные ошибки и как их избежать

  • Забытое двоеточие: после условия всегда ставится :. Без него Python не поймёт, что начался блок.
  • Смешивание операторов = и ==: = — это присваивание, == — сравнение. Внутри условия всегда нужно сравнение.
  • Сравнение строк и чисел: нельзя сравнивать строку с числом напрямую. Если считываешь число через input(), обязательно преобразуй его в int().
  • Неверные отступы: если внутри if одна строка с отступом, а следующая без — Python решит, что блок закончился. Убедись, что все строки блока сдвинуты одинаково.
