Твой первый урок на Python

Привет, будущий разработчик! Ты начинаешь путь в изучении Python — одного из самых мощных и красивых языков программирования. Мы подготовили этот учебник, чтобы твои первые шаги были уверенными, а код — чистым и понятным. Поехали!

1. Что такое программирование

Программирование — это написание чётких инструкций для компьютера. Компьютер очень быстр, но совершенно не умеет догадываться сам. Представь, что ты даешь команду роботу сварить кофе. Ему нельзя просто сказать «сделай кофе». Тебе нужно расписать шаги: «возьми кружку», «насыпь две ложки молотых зёрен», «залей кипятком».

Инструменты переводчика

  • Код: Текст, написанный по правилам языка программирования.
  • Интерпретатор: Программа-переводчик. Она читает твой код строчка за строчкой и переводит его в понятные процессору нули и единицы прямо в момент выполнения.

2. Настройка среды

Чтобы твой компьютер «понимал» Python, нужно установить инструменты с официальных сайтов:

Шаг 1. Скачай Python на python.org. При установке обязательно нажми галочку "Add Python to PATH".

Шаг 2. Установи редактор Visual Studio Code на code.visualstudio.com.

Шаг 3. В VS Code нажми Ctrl+Shift+X и установи расширение Python от Microsoft.

Шаг 4. Создай файл main.py, напиши print("Привет!") и нажми кнопку Play.

3. Функция print() и её секреты

Функция print() выводит данные на экран. Для тестирующих систем важно уметь управлять тем, как именно эти данные разделяются.

Аргумент sep (Separator)

Когда ты перечисляешь данные через запятую, Python по умолчанию ставит между ними пробел. Параметр sep позволяет заменить его на любой другой символ или убрать вовсе.

print("20", "04", "2026", sep=".")  # Выведет: 20.04.2026
print("A", "B", "C", sep="")        # Выведет: ABC (без пробелов)

Аргумент end

Обычно после выполнения print() курсор перескакивает на новую строку. Параметр end указывает, что напечатать в самом конце вместо этого перехода.

print("Загрузка...", end="")
print("Готово!")
# Результат в одну строку: Загрузка...Готово!

4. Управляющие символы

Иногда нужно напечатать то, что нельзя просто набрать на клавиатуре:

  • \n — перенос текста на новую строку.
  • \t — табуляция (большой отступ).
  • \" — кавычка внутри строки (чтобы Python не подумал, что строка закончилась).
print("Первая строка\nВторая строка")
print("Путь: C:\\Users\\Admin")
Внимание!

Тестирующая система проверяет каждый символ. Лишний пробел или маленькая буква вместо большой — это ошибка. Используй sep="" и end="", если нужно идеально подогнать ответ под требование задачи.
